PRDA – 04: Job Market Analysis

1. Project Overview

The Job Market Analysis project focuses on analyzing Data Science-related job postings to identify employment trends, salary distributions, hiring patterns, industry demand, and technical skills required by companies.

The project uses SQL for data analysis and Microsoft Power BI for data visualization. The analysis provides useful insights for job seekers and employers to understand current job market requirements and make informed decisions.

2. Project Objectives

- Identify states with the highest number of job postings.
- Analyze average minimum and maximum salaries across states.
- Identify the top five industries with the highest number of Data Science-related job postings.
- Find companies with the maximum number of job openings.
- Identify the most frequently advertised job titles.
- Analyze salary distributions across job titles.
- Identify technical skills required by companies.
- Understand the relationship between average salary and education.
- Analyze additional dataset features and derive meaningful insights.
- Create an interactive Power BI dashboard.

3. Dataset Information

- Dataset Name: Job Market Analysis
- Total Records: 742
- Total Features: 42
- Salary Currency: US Dollars (USD)

The dataset contains information about:

- Job Titles
- Salary Estimates
- Job Descriptions
- Company Names and Ratings
- Job Locations
- Company Headquarters
- Industries and Sectors
- Company Size and Revenue
- Technical Skills
- Educational Qualifications
- Job Seniority

**Note:** A value of -1 in the original dataset indicates unavailable information.

7. Power BI Dashboard

An interactive dashboard was developed using Microsoft Power BI to visualize job market trends.

The dashboard includes:

- Job postings by state.
- Average salary by state.
- Top industries.
- Top hiring companies.
- Popular job titles.
- Salary by job title.
- Technical skills demand.
- Salary and education analysis.

8. Key Outcomes

The project provides an understanding of:
